# LearnStyle AI 🧠
Personalized Education through Predictive Analytics

LearnStyle AI is an intelligent diagnostic platform designed to bridge the gap between instructional methods and student cognitive preferences. Using a research-backed VARK assessment engine and Machine Learning classification, the system identifies a student's primary learning modality to provide a customized study roadmap.

Key Features
* **AI Assessment Engine:** A 20-question diagnostic tool utilizing a 4-way scoring logic (Visual, Auditory, Read/Write, Kinesthetic).
* **Role-Based Dashboards:** Distinct interfaces for **Students** (personal growth & tips) and **Admins** (class-wide analytics).
* **Predictive Modeling:** Built to integrate with Random Forest classification for high-accuracy learning style prediction.
* **Responsive UI:** Developed with React, Tailwind CSS, and Shadcn/UI for a seamless academic experience.

Tech Stack
* **Frontend:** React (Vite), Tailwind CSS, Lucide Icons.
* **Components:** Shadcn/UI.
* **Architecture:** Microservices-ready P2P Hybrid.
* **Version Control:** GitHub with CI/CD integration.

The VARK Logic
The system calculates a **Confidence Score** by analyzing weighted responses across four cognitive categories:
1. **Visual (V):** Preference for maps, diagrams, and spatial patterns.
2. **Auditory (A):** Focus on lectures, discussions, and verbal cues.
3. **Read/Write (R):** Mastery through lists, reports, and text-based inputs.
4. **Kinesthetic (K):** Practical, hands-on application and physical movement.
